\subsection{Evaluation Protocol}

\subsubsection{Pass@k Computation}

We use the unbiased Pass@k estimator from \citet{chen2021evaluating}:
\begin{equation}
    \text{Pass@}k = \mathbb{E}_{\text{problems}} \left[ 1 - \frac{\binom{n-c}{k}}{\binom{n}{k}} \right]
\end{equation}
where $n$ is the number of samples generated per problem and $c$ is the number of correct samples.

\subsubsection{Generation Settings}

\begin{itemize}[nosep]
    \item \textbf{Sampling}: $n=20$ samples per problem
    \item \textbf{Temperature}: Selected via search (0.2 for MBPP/GSM8K/CodeContests, 0.8 for HumanEval)
    \item \textbf{Pass@k values}: $k \in \{1, 5, 10, 20\}$
    \item \textbf{Execution}: Sandboxed environment with test case validation
\end{itemize}

\subsubsection{Evaluation Methods by Benchmark}

\begin{itemize}[nosep]
    \item \textbf{HumanEval}: Function execution against hidden test cases
    \item \textbf{MBPP}: Assert statement execution
    \item \textbf{GSM8K}: Exact match of final numerical answer
    \item \textbf{CodeContests}: stdin/stdout matching against 10 test cases
\end{itemize}
